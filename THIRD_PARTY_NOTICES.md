# Third-party notices and asset provenance

This document records component provenance. It does not assign a blanket license to the scene code, generated assets, or supplied reference material.

## Franka Emika Panda

`assets/panda_tactile.xml` and `assets/franka_meshes/` derive from the Franka Panda description. The existing [Apache-2.0 license](assets/franka_meshes/LICENSE) and [upstream model README](assets/franka_meshes/UPSTREAM_README.md) are retained. The XML includes a modification notice for the gripper pads.

The model and mesh files match the earlier project [genesis-franka-cloth-bag-release at commit fb8193c422ab1630d842a7727ef520ccf32d4fd2](https://github.com/Chloe-Jinlei/genesis-franka-cloth-bag-release/tree/fb8193c422ab1630d842a7727ef520ccf32d4fd2/teddy_bag_flat_start/assets). Local symlinks were materialized in this repository.

## Teddy and paper bag

The teddy OBJ, MTL and texture match that earlier project's recorded assets. Local generation scripts describe procedural ellipsoid geometry, remeshing, scaling and a generated texture. No separate license for these project-generated teddy assets is assigned here; the Franka license does not automatically cover them.

The paper-bag mesh is generated by `build_paper_bag.py`. The runtime-optional user-supplied reference photograph is omitted from the browsable source package; the unchanged historical evidence archive retains the original reference. No license for the photograph is asserted.

## Genesis and native dependencies

The experiment uses Genesis 1.4.3, commit `ffd119c30118ebb9745fc009349efb2112a8cb76`. Its [Apache-2.0 license](licenses/Genesis_LICENSE) is included. Actual engine source and dependency versions are preserved in the Release archive.

pyuipc / libuipc 0.0.29 provides an [Apache-2.0 license](licenses/pyuipc_LICENSE) and [NOTICE](licenses/pyuipc_NOTICE), both copied unchanged. The NOTICE includes attribution for the GPU IPC work and embedded METIS/GKlib components. The Release archive retains the original package metadata and notices.

The archived vendor tree also contains Polyscope 2.6.1 (MIT) and huggingface_hub 2.4.0 (Apache-2.0); their original license files remain with their distributions. Native shared libraries retain their upstream terms. This is a record of inspected component notices, not an exhaustive license audit of transitive binaries.

No project-wide license was selected during publication. Component licenses remain scoped to their respective files.
